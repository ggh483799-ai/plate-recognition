点「开始」后一直黑屏 / 报没有读到帧？
  1. 没有可用摄像头：本页会用「能打开**且能读到一帧**」来判定设备是否可用， 只在设备列表里出现的就是可用的。一台都没有时会自动切到「本地视频」， 直接点「用示例视频试试」也能立刻看到效果。
  2. 摄像头被别的程序占用：微信/钉钉/相机应用会独占设备，关掉再试。
  3. 首帧可能要等几秒：驱动唤醒慢属正常，超过 30s 仍无帧才会判定失败（看门狗）。
  4. RTSP 地址不通或需鉴权：先用 VLC 确认这个地址能播，再填到这里。
  5. 网页视频链接（微博 / 好看视频 / 抖音 / B站等）：直接粘贴链接即可， 服务端会自动解析出真实视频地址再拉流（首次解析多花几秒属正常）。 需要登录 / 已删除 / 仅粉丝可见的视频解析不了，会明确报错。
  6. 把 backend/首帧 两个指标贴出来，就能判断是设备问题还是配置问题。
远景 / 航拍车流为什么很多车没有车牌？
  1. 这不是故障，是像素极限：车辆被检出（绿框 car 0.xx）说明检测正常， 但航拍/远景里每辆车只有几十像素宽，车牌只有 25~50 像素—— 中文车牌可靠识别需要 100px 以上且接近正面视角。实测把这类车放大 4 倍， 车牌仍是一团模糊色块，人眼也无法辨认。
  2. 调灵敏度 / 换高档位都救不了这一类：放大插值不产生新信息。
  3. 素材里近景经过的车辆（车牌占画面足够大）会被正常读出—— 右侧「识别到的车牌」列表就是本素材里全部可读的车牌。
  4. 想识别这类场景只能换卡口 / 近景机位的素材，或提高摄像机分辨率并对准车道。
玩具车 / 小车牌识别不出来？
  1. 把「识别灵敏度」调到宽松或极宽松，再点一次「开始实时识别」。
  2. 画面上会出现灰色的「疑似车牌」框——那说明检测到了， 只是置信度没过阈值（框上会写具体数值，例如"疑似车牌 检测置信度低 0.31 < 0.50"）。 连灰框都没有，就是检测这一步就没发现它。
  3. 玩具车牌不是标准车牌（识别模型按真实车牌训练），字符样式对不上时识别不出来属正常； 凑近一点、档位切 high、用正对角度会更有机会。
  4. 「画面标注」选标注车辆 / 行人后，玩具车若被当作"car"检出来， 会画绿色细框并标注 car 0.xx。
为什么画面看起来"不够流畅"？
  1. 识别是瓶颈：本机 CPU 上单次识别约 0.3–1 秒（取决于档位与画面宽度）。
  2. 画面按源帧率播放，识别按「识别频率」节流；中间帧沿用最近一次的识别结果画框。
  3. 想要更快：档位调 low、画面宽度降到 480、识别频率放到 500ms/1s。
  4. 直播源处理不过来时会丢帧追赶（单次上限约 2 秒的帧量），宁可少看几帧也不让延迟越滚越大。
  5. 真"25fps 全帧实时"需要 GPU，当前是 CPU 降级路径。
